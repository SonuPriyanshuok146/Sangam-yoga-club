# 🧘‍♂️ SANGAM Yoga Club Website

SANGAM Yoga Club is a modern and responsive yoga website designed to promote physical, mental, and spiritual well-being. The website provides information about yoga activities, leadership, and coaching while focusing on a clean user interface and smooth user experience.

This project is built as a growing platform and will be continuously enhanced with advanced technologies in the future.

---

## 🌟 Current Features
- Clean and responsive website layout  
- Yoga-themed homepage with background visuals  
- Leadership & coach section with profile cards  
- Organized content structure for easy navigation  
- Mobile-friendly and user-focused design  

---

## 🛠️ Technologies Used
- **HTML5** – Structure and content  
- **CSS3** – Styling, layouts, responsiveness  
- **JavaScript** – Interactivity and dynamic behavior
